# Karan Verma | Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS and JavaScript** as part of my Web Development internship at **Codomax Digital**.

**Live Website:** https://kxran44.github.io/my-portfolio/

## About

I am Karan Verma, a B.Tech (AI & Data Science) student at Engineering College Bikaner. This portfolio introduces me, my skills, my education and my projects in one place, and lets visitors download my resume or contact me.

## Features

- **Responsive design** that works on mobile, tablet and desktop (Flexbox and Grid)
- **Dark / Light mode** toggle, saved in the browser for the next visit
- **Mobile hamburger menu** with smooth scrolling and active link highlighting
- **Scroll reveal animations** and a back-to-top button
- **Projects section** with links to code and live demos
- **Education section** and a **downloadable resume (PDF)**
- **Contact form** with validation for name, email and message
- **Link preview card** (Open Graph) for nice sharing on LinkedIn and WhatsApp
- Inline SVG icons, so no icon library is needed

## Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/Kxran44/my-portfolio.git
   ```
2. Open the folder and double-click `index.html`, or use the **Live Server** extension in VS Code.

No build tools or installation are needed.
